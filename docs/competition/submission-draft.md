## Description draft

Bloom in Time is being designed around a simple idea: solving a puzzle should bring something to life.

The planned experience places a miniature sleeping tree in front of a seated player. Using their hands, the player rearranges pathways that carry repeating pulses of light. Bends redirect the pulses, splitters create two routes, and delay pods hold a pulse for one beat. The objective is to make every flower receive light together.

Each restored flower contributes a musical voice. As puzzles are completed, the tree becomes a living composition, giving the player a visible and audible record of progress.

The project is planned as an original TypeScript application built with Meta's Immersive Web SDK. Its puzzle rules will evaluate a directed graph using integer beat timing, independently of animation or audio. The same game commands will connect desktop controls and hand input. The intended first release contains six authored puzzles, automatic placement, undo, contextual hints, and browser-local progress.

As a solo developer without access to a physical headset, I plan to develop and record using XR emulation. Final materials will identify that testing context accurately.

Future development could explore additional miniature worlds and more elaborate timing puzzles. The competition version will focus on making the first interaction clear, the puzzles satisfying, and the garden worth returning to.
